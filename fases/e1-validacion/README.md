# Descubrimiento y validación

**Acciones:** Problema en una frase · Competencia y precios · 5–10 conversaciones reales · Techo de precio · Promesa
**Duración:** 5–10 d · **Cierra con:** 3 personas dijeron con qué presupuesto lo comprarían · **Estado:** ✅ competencia y sectores identificados

## Hecho
- Análisis competitivo para identificar la diferenciación del servicio.
- Sectores objetivo: talleres mecánicos, restaurantes, salones de belleza, consultorios médicos y dentales, gimnasios, bienes raíces, turismo dental.
- Investigación de leads: talleres y llanteras del gran San Diego **sin sitio web**.

## Diferenciación
- Flujos autónomos y complejos, no plantillas.
- Lógica específica por industria.
- Conexiones en tiempo real con sistemas externos.

## Ángulo de venta
Dolores concretos, no características: llamadas perdidas · consultas repetitivas · citas a las que el cliente no llega.
